# Short-Term Energy Consumption Forecasting

A machine learning project for forecasting short-term energy consumption using historical energy data, with data preprocessing, exploratory data analysis, feature engineering, and XGBoost-based prediction.

## Overview

This project develops a machine learning pipeline to analyze historical energy consumption patterns and forecast short-term future energy demand.

The project includes data preprocessing, exploratory data analysis, feature engineering, model development, and prediction for the next 10-minute energy consumption interval.

## Objectives

- Analyze historical energy consumption patterns.
- Perform data preprocessing and exploratory data analysis.
- Engineer relevant features for short-term forecasting.
- Train a machine learning model for energy consumption prediction.
- Generate short-term energy consumption forecasts.
